# zolotoy-dev-frontend

`zolotoy-dev-frontend` is the single frontend repository for `zolotoy.dev`, a
technical developer/admin environment for a backend portfolio.

The future SPA will provide four frontend modules:

- Order
- Auth
- Notification
- URL Shortener

Project documentation is organized as follows:

- Backend specifications: [`docs/backend-specs/`](docs/backend-specs/)
- Frontend architecture: [`docs/frontend/MASTER_FRONTEND_PLAN.md`](docs/frontend/MASTER_FRONTEND_PLAN.md)
- Codex execution prompts: [`docs/codex/`](docs/codex/)

Implementation stages are intentionally sequential:

```text
00 Foundation
→ 01 Order
→ 02 Auth
→ 03 Notification
→ 04 Shortener
→ 05 Final Integration
```

Frontend implementation has not started yet. The next task is
[`docs/codex/FRONTEND-IMPLEMENTATION-PROMPT-00-FOUNDATION.md`](docs/codex/FRONTEND-IMPLEMENTATION-PROMPT-00-FOUNDATION.md).
